# Post Box (React + Vite)

A controlled-textarea post box built with `useState`.

## Features
- Controlled `<textarea>` — content stored in state
- Live character counter (`n/100`)
- 100-character limit validation
- Error message when the limit is exceeded
- Post button disabled when the box is empty or over the limit

## Run
```bash
npm install
npm run dev
```
Open the URL shown in the terminal (usually http://localhost:5173).
